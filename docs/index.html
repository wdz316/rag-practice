一、RAG 是什么（30 秒）

大模型不会背你们公司的私域资料。RAG 的做法是：用户提问时，先去文档库里找出最相关的几段原文，再把原文和问题一起交给大模型，让它照着原文回答。好比开卷考试：书（文档库）+ 找书（检索）+ 照书写答案（生成）。

三、玩法三步

1. 输问题：比如“生命数耗完即算为什么”。口语化提问考向量，原词原文考关键词。
2. 调参数：TopK=给模型看几页（常用 5）；alpha=向量与关键词的权重，好比两条腿走路，1 只认意思，0 只认字，0.7 混合。
3. 看历史：每次查询自动记入对比表，涨绿跌红。Top1 绝对分低于 0.55 亮红灯——很可能题库不对，不要信答案。

四、分数怎么看（只记两列）

混合分：当轮排序用，第一名恒为 1，只管谁第几。向量分（绝对）：跨轮比较用，认准度。本页和仪表盘现在双列都有，对不上先看列名。

五、切分方法（6 种，仪表盘可切）

固定 500 字 / 按自然段 / 递归切分 / 标点语义边界 / 按文档结构 / 父子块。记住一句：切分是建库时定的，改切法等于重建库；仪表盘只能切换已切好的版本。
